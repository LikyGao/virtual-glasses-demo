# Experimental eyewear assets

Source: https://github.com/mahdichouchen/glasses-3d-models
Files copied unchanged: classic_black_oval.glb, classic_round.glb,
sunglasses_aviator_round.glb. PNG thumbnails are rendered from these assets.

Upstream filenames do not reliably describe the rendered shape; UI names describe
the inspected appearance instead. The upstream repository contains no LICENSE or
documented physical dimensions. These assets are included for the user's requested
evaluation; public/commercial reuse permission must be confirmed with the author.
Fit is approximate, based on face landmarks, not a calibrated millimeter measurement.
