# バーチャルメガネ試着デモ

カメラ映像に3Dのメガネを重ね、ブラウザ上でリアルタイムに試着できるデモです。
顔の位置や向きに合わせてフレームが動き、3種類のモデルを切り替えたり、試着写真をPNG形式で保存したりできます。

**顔の認識と映像の合成はデバイス内で行い、カメラ映像をサーバーへ送信しません。写真は「写真を撮る」を押した場合にダウンロードされます。**

[公開デモを開く](https://likygao.github.io/virtual-glasses-demo/)

## 現在の表示モード：v0.3.1

カメラに近い側のテンプル（つる）は、付け根から先端まで表示します。
手前側には顔・頭部による遮蔽や、耳付近でのフェードアウトを適用しません。
奥側のテンプルには頭部の遮蔽と末端のフェードアウトを残しています。
正面に近く左右の前後関係が明確でない場合は、両側を完全表示します。

これは、テンプルが途中で途切れたり、先端だけが浮いて見えたりする現象を避けるための表示方針です。
手前側のテンプルは、実際には髪や耳に隠れる位置でも表示されます。
ダウンロードする写真にも同じ表示方針が適用されます。

ページ下部の **`v0.3.1 · 手前のテンプルを全表示`** で、読み込まれた表示モードを確認できます。

## 主な機能

- MediaPipeによる顔の検出と頭部姿勢の推定
- 位置、拡大・縮小、左右の回転、上下の傾き、首の傾きに追従する3Dフレーム
- 実際の3Dモデルから生成したサムネイルによるフレーム選択
- 自撮りと同じ左右反転表示
- カメラの開始・停止、アクセス権限やモデル読み込みエラーの日本語表示
- メガネを合成した写真のPNGダウンロード

| フレーム | モデルファイル |
| --- | --- |
| ハートフレーム | `public/models/classic_black_oval.glb` |
| ブラックスクエア | `public/models/classic_round.glb` |
| スクエアサングラス | `public/models/sunglasses_aviator_round.glb` |

配布元のファイル名と実際の形状が一致しないため、画面上の名前はモデルの見た目に合わせています。

## クイックスタート

### 必要な環境

- Node.js 22.12以上、またはNode.js 24系。CIは22系、クラウド開発環境は24.19.0で確認しています。
- npm
- WebGLとカメラに対応したブラウザ
- 初回の顔認識モデル・WASMファイル取得に必要なインターネット接続

```bash
npm ci
npm run dev
```

開発サーバーの既定ポートは `5173` です。
ブラウザで `http://localhost:5173` を開き、「カメラをオンにする」を押してカメラへのアクセスを許可してください。

### カメラのアクセス権限

カメラを利用するには、HTTPSまたはlocalhostの安全なコンテキストが必要です。
スマートフォンからLAN内のHTTPアドレスへ直接アクセスしても、カメラを利用できない場合があります。
スマートフォンで試す場合は、HTTPSの公開デモなどを利用してください。

アクセスを拒否した場合は、ブラウザのサイト設定でカメラを許可し、再度カメラをオンにしてください。

## 実装の概要

### 位置と姿勢の推定

MediaPipeの顔認識結果から、目頭の中点をフレームの基準位置として使います。
視線移動によって動く虹彩中心を基準にしないことで、目線を変えた際のフレームのずれを抑えています。

フレームの大きさは左右の目尻間の3D距離から求めます。
向きは顔の変換行列から取得し、行列がない場合はランドマークから推定します。
位置・大きさ・回転を共通の時間ベースのフィルターで平滑化します。

### モデルの調整と遮蔽

モデル全体の外接範囲ではなく、前面フレームの幅とレンズ中心を使ってサイズと基準点をそろえます。
テンプルは頭幅に合わせて外側へ調整します。実寸のミリメートル情報に基づく校正ではありません。

顔の468頂点のメッシュと、顔の輪郭から後方へ延ばした頭部メッシュを、色を表示しない深度用の形状として使います。
ただし、現在の表示モードでは手前側のテンプルを別の描画パスで重ね、頭部の深度と末端のフェードを適用しません。
フレームとの接続やテンプル自体の前後関係には、メガネの深度を利用します。

### 映像の合成と写真保存

カメラ映像と3D描画結果を同じCanvasへ合成し、それぞれを一度だけ左右反転して自撮り表示にそろえます。
Canvasの解像度はカメラ映像の解像度に合わせます。

「写真を撮る」で合成済みCanvasをPNGとして保存します。
ファイル名は `virtual-glasses-YYYYMMDD-HHmmss.png` です。

### ライフサイクル

- フレームを切り替えてもカメラや顔認識モデルを再起動しません。
- 同じ動画フレームに対する推論の重複を避けます。
- タブが非表示の間は検出と描画を一時停止します。
- 顔認識モデルの読み込みはモジュール単位で共有します。
- GPUで顔認識を初期化できない場合はCPUへフォールバックします。
- コンポーネントの終了時にはカメラのトラックと3D描画リソースを解放します。

## フレームの追加・調整

設定は `src/data/glasses.ts` の `GLASSES_CATALOG` にまとめています。

| 設定 | 内容 |
| --- | --- |
| `name` / `caption` | 画面に表示する名前と説明 |
| `assetUrl` | 選択画面のサムネイル |
| `modelUrl` | GLBモデルのパス |
| `modelRotation` | 読み込み時の向きの補正。単位はラジアン |
| `frontMesh` / `lensMesh` | 前面フレームとレンズを識別するメッシュ名 |
| `widthScale` | 目尻間の3D距離に対するフレーム幅の倍率 |
| `fitOffset` | フレーム幅を1とした位置補正。正のZ方向はカメラ側 |

新しいGLBを `public/models/` に置き、モデル内のメッシュ名と座標を確認して設定を追加してください。
既存の設定をコピーするだけで正しくフィットするとは限りません。
左右のテンプル、前面フレーム、レンズを識別できる構造を想定しており、読み込み後の形状と材質も確認が必要です。

## テストと検証

```bash
# Chromiumが未インストールの場合
npx playwright install chromium

npm test
```

テスト設定は、利用可能な場合に `/usr/bin/chromium` を使用し、それ以外はPlaywrightのChromiumを使用します。
4つの回帰テストで、位置・姿勢の安定性、前面フレームの保持、連続した左右回転、
手前側テンプルの完全表示と奥側の遮蔽を確認します。
手前側は、遮蔽とフェードのない参照画像と画素単位で比較します。

自動回帰テストは合成ランドマークを使うため、すべての実際の顔や撮影条件での見た目を保証するものではありません。

実際の画像・動画を使う追加検証では、公式の `face_landmarker.task` をローカルに用意し、開発サーバーを起動した状態で次を実行できます。
動画の処理にはffmpegも必要です。

```bash
node scripts/validate-profile.mjs --model /path/face_landmarker.task --video /path/turning-head.mp4 --output /tmp/profile-report.json
node scripts/validate-profile.mjs --model /path/face_landmarker.task --image /path/profile.png --mirror --output /tmp/profile-stills.json
```

手順と判定方法の詳細は [実装・検証ドキュメント](docs/3d-fitting.md) を参照してください。
`docs/side-profile-validation.json` は以前の表示方針での結果であり、v0.3.1の測定結果ではありません。

## デプロイ

本番ビルド後の `dist/` を静的ホスティングへ配置できます。
このリポジトリでは、`main` へのプッシュ時にGitHub Actionsの **Deploy to GitHub Pages** ワークフローが実行されます。

## 制限事項とモデルの利用条件

- 同時に検出する顔は1人です。
- 手前側のテンプルは完全表示を優先するため、髪や耳の上に重なります。
- 奥側の頭部形状は近似です。髪の毛、耳、手などの厳密な遮蔽は行いません。
- 実寸、瞳孔間距離、装用感を測定する機能はありません。大きな横向きや個人差によってずれが生じます。
- 正投影の3D描画であり、実際のカメラのレンズや遠近感を完全に再現するものではありません。
- 材質には環境光を使いますが、現実の照明やレンズの屈折を正確には再現しません。
- GLBモデル3点の合計は約13MBです。初回は、これに加えて約4MBの顔認識モデルとWASMランタイムの取得が必要です。

メガネモデルの出典は [mahdichouchen/glasses-3d-models](https://github.com/mahdichouchen/glasses-3d-models) です。
配布元にはモデルのライセンスと実寸の説明が見当たらないため、公開・商用利用に必要な許可を確認する必要があります。
モデルの出典・取得時点は [public/models/SOURCE.md](public/models/SOURCE.md)、
MediaPipeおよびWebAR.rocksに関する通知は [public/licenses/](public/licenses/) を参照してください。
